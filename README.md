# «Амазонка» и «Смак.BY», Могилёв: материалы для обращений в государственные органы

Рабочая папка юридико-аналитического проекта. Здесь собраны сведения о возможных нарушениях в двух заведениях общественного питания в Могилёве — рестобаре «Амазонка» (ул. Ленинская, 38; ООО «АмазонкаГрупп», УНП 791349254) и «Смак.BY» (ул. Будённого, 13/44; продавец не установлен), — выписки норм права Республики Беларусь и проекты обращений в компетентные органы.

> **Отзывы и публикации — не доказательства.** Это сведения из открытых источников, по существу не проверенные. Официально установлен один вид нарушения: продукты с истекшим сроком годности (дважды, по записям санитарной службы). Всё остальное — поводы просить орган о проверке.

Что важно знать до подачи:

- **О внеплановой проверке письма не просят.** По Указу Президента от 06.06.2025 № 227, если проверка, назначенная по сообщению гражданина, нарушений не подтвердит, заведение вправе требовать с заявителя возмещения убытков. Письма просят ответ по документам органа, выход на место, мониторинг, запрос документов и меры по результатам; дописать просьбу о проверке может только заявитель-очевидец (вставка в шапке каждого письма).
- **Не более двух писем от одного заявителя в одну организацию за год** (статья 8¹ Закона об обращениях). В горисполком писем четыре (П2, П3, П7, П8): их подают два заявителя или коллективно.
- **Письма о «Смак.BY» (П6–П9) срочные:** продажа объявлена до 29.11.2026.
- Один текст нескольким людям для отдельной подачи не раздавать (статья 25¹ Закона об обращениях).
- Если ответ окажется отпиской — [шаблон жалобы в вышестоящую организацию](letters/shablon_zhaloba-na-otvet.md) ([docx](letters/shablon_zhaloba-na-otvet.docx)).

Письмо в МЧС отложено: остался проект от 15.11.2026 — [md](letters/mchs_amazonka_pozharnaya-bezopasnost.md), [docx](letters/mchs_amazonka_pozharnaya-bezopasnost.docx), [перечень публикаций](letters/mchs_amazonka_pozharnaya-bezopasnost_prilozhenie-1.md); адресат не сверен. Прежние проекты, заменённые набором, — в [letters/_archive/](letters/_archive/).

Исходные описания приложений лежат в [letters/_src/](letters/_src/). Приложения и файлы Word всех писем пересобирает `bash letters/_build_docx.sh`; форму письма проверяет `python -I -X utf8 tools/letter_standard_check.py letters/<имя>.md`.

## Правила, которые нельзя нарушать

- **Только факты с источником.** Каждое утверждение опирается на материал из `sources/`; предположения помечаются как предположения.
- **В письмах — «прошу проверить»,** без утверждений о доказанных нарушениях. Слухи и догадки в обращения не идут.
- **Нормы — только по официальным текстам,** цитаты сверяются программой.
- **Персональные данные.** Объект проверки — юридическое лицо и заведение. Сведений о частной жизни не собираем; имена авторов отзывов в обращениях — только с их согласия или обезличенно.
- **Два заведения исключены из работы** решением пользователя от 15.11.2026: сведения о них не собираются и не хранятся, их упоминания в текстах заменены пометкой «[исключено]».
- **Файлы источников не правятся.** В репозитории они хранятся байт в байт (`.gitattributes`), чтобы сходились контрольные суммы.

Полный текст правил — в [CLAUDE.md](CLAUDE.md).
