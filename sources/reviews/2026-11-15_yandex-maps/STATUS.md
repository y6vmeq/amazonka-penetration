## 4. Препятствия

- Капчи не было ни разу. Вход нигде не выполнялся.
- Окно о cookie на Яндекс Картах закрыто кнопкой «Allow essential cookies» (только необходимые).
- Браузер показывает даты в своём часовом поясе (на этой машине Europe/Warsaw). Для выгрузки `raw/001`, `raw/002`, `raw/008`–`raw/012` и всех скриншотов пояс браузера переключён на Europe/Minsk (CDP `Emulation.setTimezoneOverride`), чтобы дата на странице совпадала с белорусской. Точное время в UTC есть в каждой записи (`notes`).
- Скриншоты карточек — 560 px шириной (1x): при увеличенном окне (932×2000) Playwright сбрасывает масштаб в 1.
- У 32 отзывов «Амазонки» автор без публичного профиля: отдельной ссылки на отзыв страница не даёт, в `url` стоит вкладка отзывов.

- **`REPORT.md` исполнителем не создан.** Среда, в которой запущен агент, запрещает субагентам записывать файлы отчётов: запись `REPORT.md` отклонена с сообщением «Subagents should return findings as text, not write report files». Обходить запрет другими средствами агент не стал. Полный текст отчёта будет в итоговом сообщении агента — координатору нужно сохранить его в `REPORT.md` самому. Ключевые сведения на случай обрыва сессии продублированы ниже, в разделе 7.
