# Рабочие скрипты прохода

Скрипты, которыми при сборе разбирались страницы и собирались записи. Нужны, чтобы повторить или проверить шаги сбора.

<!-- dir-readme:start -->
## Что в этой папке

| Файл или папка | Что это |
|---|---|
| [build_index.py](build_index.py) | Собирает рабочий указатель всех фото: файл, лист, SHA-256, отзыв или номер галереи, заведение, дата. |
| [crop.py](crop.py) | Вырезает и увеличивает фрагмент фото (для чтения текста и мелких деталей). |
| [exif_dates.py](exif_dates.py) | Выписывает из EXIF каждого фото дату съёмки, модель камеры и признак наличия GPS (без координат). |
| [quad.py](quad.py) | Собирает лист из нескольких фото крупными ячейками (для просмотра группами по 4–6). |
| [view.py](view.py) | Делает уменьшенные копии фото для просмотра (во временной папке, не в проекте). |
