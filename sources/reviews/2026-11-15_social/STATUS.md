## Технические находки (важно для продолжения)

1. **Telegram.** `https://t.me/s/<канал>?q=<слово>` ищет по основе слова («амазонк» находит все падежи); листать назад — `&before=<наименьший id>`. Комментарии к посту без входа: `https://t.me/<канал>/<id>?embed=1&discussion=1&comments_limit=100` (если у канала есть обсуждения). Чаты (группы) без входа не читаются.
2. **ВКонтакте.** `fetch_raw.py` с заголовком `Accept: text/html…` получает пустую оболочку; без этого заголовка (режим `vk` в `fetch2.py`, так же работает `vksearch.py`) vk.com отдаёт страницу с данными. Посты лежат в атрибуте `data-exec` (JSON, экранированный дважды), комментарии — в HTML. `m.vk.com` отвечает «Ваш браузер устарел». Общий поиск vk.com (посты по хэштегу, сообщества, видео) гостю результатов не отдаёт — нужен браузер, возможно вход.
3. **Проверка дословности для VK.** Из-за двойного экранирования `reviews_check.py` не находит текст поста в исходной странице. Поэтому для записей VK `raw_file` указывает на `raw/<имя>.decoded.json` — тот же JSON после одного `html.unescape` (скрипт `vk_decode.py`, журнал `raw/derived.jsonl` с SHA-256 исходной страницы). Исходные страницы лежат рядом, в `notes` каждой записи назван исходный файл.
4. **TikTok.** Страницы тегов и поиска без браузера пустые, но встраиваемая страница `https://www.tiktok.com/embed/tag/<тег>` отдаёт число видео и до 8 верхних роликов с описаниями. Страница видео отдаёт описание, дату и счётчики в `__UNIVERSAL_DATA_FOR_REHYDRATION__`; комментарии закрыты (окно входа и пазл — не проходить). Профиль: `statusCode 10221` = такого аккаунта нет.
5. **YouTube.** `https://www.youtube.com/results?search_query=…` отдаёт выдачу в `ytInitialData`, страница видео — описание и дату в `ytInitialPlayerResponse`.
6. **Поисковики.** `WebSearch` по-русски и с `site:` почти бесполезен. DuckDuckGo недоступен (сброс соединения), Яндекс — капча (не проходил), Bing — пусто, tgstat — 403. Работают: Yahoo Search (`ysearch.py`), Brave Search (`search.py`, но 429 после 2–3 запросов).
