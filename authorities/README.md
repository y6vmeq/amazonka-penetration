## 4. Кто рассматривает обращение первым (Указ Президента № 498)

Выписка — `law/ukaz-498-2007_kuda-obrashchatsya.md`. Куда бы ни было отправлено обращение, сначала его рассматривает местный орган по месту, где возник вопрос; его решение обжалуется в вышестоящий орган из той же строки перечня.

| Тема | Местный орган (по перечню Указа) — для Могилёва | Вышестоящий |
|---|---|---|
| Торговля, общественное питание, права потребителей | управление торговли и услуг Могилёвского горисполкома | подразделение облисполкома по торговле и услугам; МАРТ |
| Санитарно-эпидемиологическое благополучие | в перечне названы областные центры гигиены, эпидемиологии и общественного здоровья — Могилёвский областной центр (ул. Гришина, 82); городской зональный центр — территориальная организация той же системы | Министерство здравоохранения |
| Чеки, приём оплаты, касса, оборот алкоголя и табака | инспекция МНС по Могилёвской области | Министерство по налогам и сборам |
| Разрешения на строительные работы, перепланировка | подразделение горисполкома по архитектуре и строительству | подразделение облисполкома |
| Строительный надзор | инспекция Департамента контроля и надзора за строительством по Могилёвской области | Департамент; Госстандарт |
| Жилищный фонд (каналы, подъезд, фасад жилого дома) | организация, эксплуатирующая жилищный фонд; подразделение исполкома по жилищно-коммунальному хозяйству | подразделение облисполкома; Министерство жилищно-коммунального хозяйства |
| Труд | областное управление Департамента государственной инспекции труда | Департамент; Министерство труда и социальной защиты |

Охраны наследия, пожарной безопасности, рекламы, ветеринарии и персональных данных в перечне нет: действует общее правило о местном органе.

## 5. Общие правила подачи

- Электронные обращения во все государственные органы — только через обращения.бел (так указано на страницах горисполкома, зонального центра гигиены и департамента инспекции труда). Суть нельзя излагать ссылками на интернет-ресурсы.
- По вопросам защиты прав потребителей сначала обращаются в местный исполнительный и распорядительный орган по месту нахождения объекта (страница горисполкома).
- Орган, получивший обращение не по своей компетенции, в пять рабочих дней пересылает его или возвращает с разъяснением, куда обратиться.
- Ответ обжалуется в вышестоящую организацию, затем в суд.
