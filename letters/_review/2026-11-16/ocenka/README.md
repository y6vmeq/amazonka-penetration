# Итоговая оценка писем

Приёмочные оценки независимых оценщиков по критериям К1–К8 (задание — `../ZADANIE_ocenka.md`). На каждое письмо два оценщика на разных моделях: «а» — строгий юрист-практик, «б» — редактор-делопроизводитель; повторные круги — файлы с цифрой перед расширением. Письмо принято, если у каждого оценщика по каждому критерию не меньше 9,5.
